# TaskFlow – Task Manager App

A simple and user-friendly task management web application built with React. TaskFlow helps users organize daily tasks, track progress, manage deadlines, and visualize productivity through an interactive dashboard and reports.

## 🚀 Features

- **Dashboard:** View task statistics and an overview of your productivity.
- **Task Management:** Add, edit, delete, and mark tasks as completed.
- **Task Status Tracking:** Monitor pending, completed, and overdue tasks.
- **Search and Filtering:** Find tasks and filter them based on their status or category.
- **Reports & Analytics:** View task completion statistics, category-wise progress, and productivity insights.
- **Date Filtering:** Generate reports for a selected date range.
- **Data Persistence:** Save tasks in browser local storage so they remain available after refreshing the page.
- **Responsive Interface:** Navigate between different sections using a sidebar.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** JavaScript
- **Styling:** CSS
- **Data Storage:** Browser Local Storage
- **Development Tools:** Node.js, npm, Visual Studio Code
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd task-manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📊 How It Works

1. Open the Dashboard to view an overview of your tasks.
2. Navigate to the Tasks section to create and manage tasks.
3. Update task statuses as you make progress.
4. Visit the Reports section to analyze completion rates and category-wise progress.
5. Apply date filters to view reports for a specific period.

## 💾 Data Storage

TaskFlow uses browser **Local Storage** to persist task data. Tasks are saved in the user's browser and remain available after a page refresh.

Since the application uses Local Storage, task data is not automatically synchronized between different devices or browsers.
